Optional validation addon

One strict rule. One error owner.

A11y Autocomplete keeps the combobox interaction and suggestion status. A11y Form Validator owns strict selection errors, the error summary, and focus after a blocked submit.

Working integration

Choose a departure city

Try submitting “Unknown”, then choose a suggestion with the keyboard. This example validates on submit and clears the error as soon as you choose a valid option.

    const autocomplete = createAutocomplete(root, {
  items: cities,
  strict: true,
  validationMode: "external"
});

const preset = createDefaultPreset();
const validator = createFormValidator(form, {
  ...preset,
  validateOn: ["submit"],
  rules: { city: { autocompleteSelection: true } },
  addons: [
    ...preset.addons,
    createAutocompleteFormValidatorAddon({
      fields: [{ name: "city", autocomplete }]
    })
  ]
});

    Manual announcement and focus check

    1. Type “Unknown”, submit, and confirm the validator summary is announced and receives focus.
    2. Follow the summary link and confirm it focuses the combobox input.
    3. Select Athens with Arrow Down and Enter, then confirm the inline error and summary entry clear without a duplicate announcement.
    4. Submit again and confirm the hidden city ID is ath.

    Deployment note: local development uses the installed validator package. The published example loads the pinned 1.0.19 module from jsDelivr and sends no form values to it.
