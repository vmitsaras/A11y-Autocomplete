Manual keyboard and announcement check

  1. Type “Incl”, use Arrow Down, and press Enter. Confirm only “Inclusive design” is added.
  2. Type a unique topic and press Enter without moving to a suggestion. Confirm the custom tag is added.
  3. Open suggestions and press Escape. Confirm the popup closes but the draft remains; press Escape again to clear it.
  4. Use Backspace from an empty field, then Arrow keys and Delete to review tag-removal focus behavior.

Ownership note: autocomplete announces result availability. Tag input announces additions, removals, limits, and validation failures.
