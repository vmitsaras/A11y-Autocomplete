# Changelog

This package uses Changesets for release notes.

## 1.0.0

Initial public release.

- Provide progressively enhanced autocomplete with local and async suggestions, grouped options, keyboard navigation, status announcements, strict selection, and lifecycle cleanup.
- Add a native datalist adapter that preserves authored form values and restores native behavior on destroy.
- Include optional form validator and tag input integrations through separate package entry points.
- Provide opt-in integration diagnostics, TypeScript declarations, CSS, and documented examples.
- Include automated unit, browser, accessibility, and responsive layout checks. Manual assistive technology verification remains pending as documented in ACCESSIBILITY.md.
